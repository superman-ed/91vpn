# 91VPN Web 面板 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 复刻 socloud 机场的 Web 面板，跑通"注册→买套餐→拿订阅→连上网"主线。

**Architecture:** Laravel 11 单体，Blade+Tailwind 前台，Service 层承载计费/订阅/流量结算，MySQL+Redis，Docker Compose 编排。API 分订阅下发(`/sub`)和节点对接(`/mod_mu`)。

**Tech Stack:** PHP 8.3 / Laravel 11 / MySQL 8 / Redis / Tailwind / Sanctum / Docker Compose。

**Spec:** `docs/superpowers/specs/2026-08-22-web-panel-design.md`

## Global Constraints

- PHP **8.3**，Laravel **11**（本地 PHP 是 7.4，太老——所有 php/composer/artisan 命令必须在 Docker `app` 容器内跑，不用宿主机 PHP）。
- 密码哈希 **argon2id**（`config/hashing.php` driver=argon2id），禁用 md5。
- CSRF 全站开启（Laravel 默认，不关）。
- 流量用 **bigint 存字节**，显示层转 GB。
- 节点鉴权用**每节点独立 secret**，禁用公共默认密钥。
- 测试用 Pest（Laravel 11 默认可选）或 PHPUnit；本计划用 **Pest**。
- 每个 Task 结束 commit；提交信息末尾加 `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`。
- 项目根 `/home/dev/web/91vpn`，代码放项目根（`refs/` 已 gitignore）。

# 里程碑 M0：脚手架

**目标**：`docker compose up` 起得来，Laravel 跑通，8 表迁移+模型+seeder 就绪，首页返回 200。

### Task M0.1：Docker 环境 + Laravel 骨架

**Files:**
- Create: `docker-compose.yml`, `docker/php.Dockerfile`, `docker/nginx.conf`
- Create: Laravel 项目文件（composer create-project 生成）

**Interfaces:**
- Produces: 可运行的 Laravel 应用；容器名 `app`(php-fpm)、`web`(nginx)、`db`(mysql)、`redis`。artisan 通过 `docker compose exec app php artisan ...` 调用。

- [ ] **Step 1: 写 php.Dockerfile**

```dockerfile
# docker/php.Dockerfile
FROM php:8.3-fpm
RUN apt-get update && apt-get install -y git unzip libzip-dev libpng-dev \
    && docker-php-ext-install pdo_mysql zip bcmath gd \
    && pecl install redis && docker-php-ext-enable redis
COPY --from=composer:2 /usr/bin/composer /usr/bin/composer
WORKDIR /var/www/html
```

- [ ] **Step 2: 写 docker-compose.yml**

```yaml
services:
  app:
    build: { context: ., dockerfile: docker/php.Dockerfile }
    volumes: [".:/var/www/html"]
    depends_on: [db, redis]
  web:
    image: nginx:alpine
    ports: ["8080:80"]
    volumes: [".:/var/www/html", "./docker/nginx.conf:/etc/nginx/conf.d/default.conf"]
    depends_on: [app]
  db:
    image: mysql:8
    environment:
      MYSQL_DATABASE: vpn
      MYSQL_ROOT_PASSWORD: root
    ports: ["3306:3306"]
    volumes: ["dbdata:/var/lib/mysql"]
  redis:
    image: redis:7-alpine
volumes: { dbdata: {} }
```

- [ ] **Step 3: 写 nginx.conf**

```nginx
server {
    listen 80;
    root /var/www/html/public;
    index index.php;
    location / { try_files $uri $uri/ /index.php?$query_string; }
    location ~ \.php$ {
        fastcgi_pass app:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

- [ ] **Step 4: 用容器创建 Laravel 项目**

Run:
```bash
docker compose build app
docker compose run --rm app composer create-project laravel/laravel:^11 tmp_laravel
# 把 tmp_laravel 内容移到项目根（保留 docker/、docs/、refs/、.gitignore）
docker compose run --rm app bash -c "cp -rn tmp_laravel/. . && rm -rf tmp_laravel"
```
Expected: 出现 `artisan`、`composer.json`(laravel/framework ^11)、`app/`、`public/`。

- [ ] **Step 5: 配 .env（数据库/redis/argon2）**

修改 `.env`：
```
DB_CONNECTION=mysql
DB_HOST=db
DB_PASSWORD=root
DB_DATABASE=vpn
REDIS_HOST=redis
CACHE_STORE=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis
```
修改 `config/hashing.php`：`'driver' => 'argon2id'`。

- [ ] **Step 6: 起服务并验证首页**

Run:
```bash

docker compose exec app php artisan key:generate
curl -s -o /dev/null -w "%{http_code}" http://localhost:8080
```

Expected: `200`（Laravel 欢迎页）。

# 里程碑 M1-M5（任务级分解，执行到各里程碑时展开为 bite-sized 步骤）

> 每个 Task 遵循 TDD：先写 Feature/Unit 测试 → 跑失败 → 实现 → 跑通 → commit。展开细步骤时套用 M0 的模式。

## M1 认证

- **Task M1.1 注册**：`Auth/RegisterController`。测试：POST /register 带邮箱/密码/邀请码/算术码 → 建 user，自动生成 uuid(Str::uuid)、passwd(Str::random)、invite_token、api_token，class=0。算术验证码用 session 存答案。邀请码校验 invite_codes 表，写 ref_by。
- **Task M1.2 邮箱验证码**：`/auth/send` 生成 6 位码存 Redis(5分钟)，第一版 Log::info 输出(不真发)。注册校验码。
- **Task M1.3 登录/登出**：`Auth/LoginController`，Laravel session。测试：正确密码登录成功，错误失败，登出清 session。
- **Task M1.4 找回密码**：重置链接(token 存 Redis)，第一版 Log 输出。

Produces: 认证后 `auth()->user()`；注册产出的 user 带全套 token。

## M2 用户中心

- **Task M2.1 仪表盘**：`User/DashboardController` + Blade。显示 transfer_enable/u+d/剩余(字节转GB)、class_expire、class 名(VIP①)、money。Helper `bytesToGB()`。
- **Task M2.2 签到**：POST /user/checkin，每日一次(last_check_in 存 user 或 Redis)，随机加 100-500MB 到 transfer_enable。
- **Task M2.3 节点设置**：显示订阅链接 `/sub/{invite_token}`；POST 重置 invite_token；POST 重置 passwd(连带 uuid=Str::uuid())。
- **Task M2.4 公告**：列表展示 announcements(published=true)。

Consumes: M1 的 auth。Produces: 用户能看到订阅链接(供 M4)。

## M3 商店与计费

- **Task M3.1 套餐列表**：`User/ShopController`，展示 plans(on_sale)，周期选择前端算价。
- **Task M3.2 下单**：POST /user/order/create → 建 order(status=pending, amount)。
- **Task M3.3 BillingService 发货（核心，Unit 测试重点）**：
  ```
  deliver(User $u, Plan $p): transfer_enable += p.transfer_gb*1024^3;
  class=p.class; class_expire=max(now,class_expire)->addDays(p.duration_days);
  node_speed_limit=p.speed_limit; node_ip_limit=p.ip_limit; order.status=paid
  ```
  Unit 测试：给定 user+plan，调 deliver，断言各字段正确(含叠加续期 max 逻辑)。
- **Task M3.4 模拟支付**：POST /user/order/{id}/mock-pay → 调 BillingService::deliver → 跳仪表盘。真网关接口预留(PaymentGateway interface)。
- **Task M3.5 钱包**：余额展示、模拟充值(写 balance_logs)、余额支付订单。

Consumes: M2。Produces: 买套餐后 user 流量/等级/到期更新(供 M4/M5 筛节点)。

## M4 订阅下发

- **Task M4.1 rules 模板**：把 socloud Clash 配置的 proxy-groups + rules(约700条)存 `resources/clash/rules.yaml`(静态)。来源：refs/socloud/subscription。
- **Task M4.2 SubscriptionService**：
  ```
  generateClash(User $u): 校验未过期/未封 → 查 nodes where class<=u.class → 
  每节点生成 {name,type:vmess,server,port,uuid:u.uuid,alterId:0,cipher:auto,udp:true} →
  注入模板的 proxies + proxy-groups → 返回 YAML
  ```
  Unit 测试：给 user+nodes，断言 YAML 含节点、uuid 正确、过期用户返回空/拒绝。
- **Task M4.3 SubController**：`GET /sub/{token}` → 查 user by invite_token → SubscriptionService → 返回 `Content-Type: application/yaml`。Feature 测试：有效 token 返回配置，无效 404。

Consumes: M2(invite_token)、M3(class)。Produces: 客户端可导入的订阅。

## M5 节点 WebAPI

- **Task M5.1 NodeSecret 中间件**：校验 query `key` == node.secret，否则 401。
- **Task M5.2 拉用户名单**：`GET /mod_mu/users?node_id=X`。NodeUserService::servableUsers(node)：where banned=0 AND class_expire>now AND class>=node.node_class AND (u+d < transfer_enable)。返回 [{id,uuid,speed_limit,ip_limit}]。Feature 测试：过期/超流量用户被排除。
- **Task M5.3 收流量结算**：`POST /mod_mu/users/traffic?node_id=X`。TrafficService::record(node, [{user_id,u,d}])：每条 `user.u += u*rate; user.d += d*rate`。Unit 测试：倍率结算正确，累计正确。
- **Task M5.4 心跳/在线IP**：`GET /mod_mu/func/ping` 更新 node.last_heartbeat/online；`POST /mod_mu/users/aliveip` 第一版记录不强制。
- **Task M5.5 端到端手动验证**：文档化"装 XrayR 接面板"步骤(需 VPS，本地可用假上报模拟)。

Consumes: M3(user 计费字段)、M0(node.secret)。Produces: 🎯 完整主线。
