# 阿里云邮件推送（DirectMail）配置指南

用于注册 / 找回密码的邮箱验证码发送。选它的理由：对国内邮箱（QQ / 163 / 126）送达友好。
面板已支持通用 SMTP，**填参数即可，无需改代码**。

## 前提

需要一个**自己的域名**（用来配发信域名 + DNS 解析）。没有域名先注册一个。

## 一、阿里云侧准备

1. **开通服务**：阿里云控制台搜索「邮件推送 / DirectMail」，开通（按量付费，验证码这点量几乎免费）。

2. **添加发信域名**：
   - 邮件推送 → 发信域名 → 新建域名，填一个子域名，如 `mail.你的域名.com`
   - 按控制台提示，去你的域名 DNS 解析里加这几条记录：
     - **TXT**（SPF）：`v=spf1 include:spf.dm.aliyun.com ~all`
     - **TXT / CNAME**（DKIM）：控制台给的那条
     - **MX**：`mxdm.aliyun.com`（阿里云给的）
     - **TXT**（`_dmarc`，可选但建议）：`v=DMARC1;p=none;rua=mailto:你的邮箱`
   - 回控制台点「验证」，全部通过即可。

3. **创建发信地址**：
   - 发信地址 → 新建，如 `noreply@mail.你的域名.com`
   - 邮件类型选「触发邮件」（验证码属于触发类）
   - **设置 SMTP 密码**（重要，记住它——这不是阿里云账号密码）

## 二、填进面板「站点设置 → 邮件发送」

| 字段 | 值 |
|---|---|
| SMTP 服务器 | `smtpdm.aliyun.com` |
| 端口 | `465` |
| 加密 | SSL |
| 用户名 | 发信地址，如 `noreply@mail.你的域名.com` |
| 密码 | 上一步设置的 **SMTP 密码** |
| 发件人地址 | 同用户名 |
| 发件人名称 | 91VPN |

> 备注：新加坡/海外节点用 `smtpdm-ap-southeast-1.aliyuncs.com`；国内用 `smtpdm.aliyun.com`。

## 三、验证

- 保存后，走一次注册 / 找回密码，收邮箱看有没有收到验证码。
- 后台「系统 → 邮件记录」能看到每封的结果：`sent` 成功 / `failed` 失败（带错误原因）。
- 收不到但显示 `sent`：查垃圾箱；或用「邮件记录 → 验证码代查」当场取码告知用户。

## 常见问题

- **displayed failed，报鉴权错误**：用户名/密码填错，或密码填成了阿里云账号密码（应填发信地址的 SMTP 密码）。
- **进垃圾箱**：DNS 的 SPF/DKIM 没配全，或发信域名信誉未建立；配齐 SPF+DKIM+DMARC 会明显改善。
- **限流**：新账号有初始额度，量大在控制台申请提额 / 独立 IP。
